# Security Policy

## Supported Versions

Only the **latest released version** of this Firefox extension receives security updates. Older versions are not maintained.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, use GitHub's **Private vulnerability reporting** feature:

1. Go to the [Security tab](https://github.com/xolli/ChatGPT-Ctrl-Enter-Sender-Firefox/security) of this repository
2. Click **Report a vulnerability**
3. Fill in the form with as much detail as possible (affected version, steps to reproduce, potential impact)

This project is maintained by one person in their spare time. I aim to:

- Acknowledge the report within about **7 days**
- Share a status update within about **30 days**
- Coordinate disclosure once a fix is released

Thank you for helping keep this project and its users safe.
